PayFast Configuration

JazzCash / Easypaisa / Bank / Raast

Fill in Merchant ID, Secured Key and Base URL above, then add a Payment Method in the Payment Methods tab with code PAYFAST. Works for wallet top-up and direct product purchase. No webhook/notify URL needs to be registered anywhere — the callback URL is sent fresh with every transaction automatically.

Binance / Bybit Verification

Pay ID top-ups can auto-credit like on-chain deposits when API keys are set and Payment Methods → Binance Pay / Bybit Pay are marked Auto. Use read-only API keys (no withdrawal permission).

  • BINANCE_PAY_ID — shown to users for Binance Pay top-ups.
  • BYBIT_PAY_ID — shown to users for Bybit Pay top-ups.
  • BEP20_USDT_ADDRESS / TRC20_USDT_ADDRESS — on-chain USDT addresses.
  • BINANCE_API_KEY + BINANCE_API_SECRET — Binance Pay transaction history + deposits.
  • BYBIT_API_KEY + BYBIT_API_SECRET — Bybit Pay internal deposits + on-chain deposits.

After a user pays and pastes the order / transfer ID, the bot matches it in Binance Pay history or Bybit internal deposit history and credits the wallet automatically (Auto Verify Payments above must be on).
